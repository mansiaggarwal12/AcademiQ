# Companion Explanation: AcademiQ_Train_Preprocessed.csv

## A. Academic Understanding: Fully Transformed Numeric Design Matrices
- **The Need for Numeric Arrays:** While tree models can theoretically split on strings, mathematical algorithms (OLS matrix inversion, SVM quadratic programming, K-Means Euclidean distance, PCA singular value decomposition) require strictly real-valued matrices $\mathbf{X} \in \mathbb{R}^{n 	imes p}$.
- **One-Hot Dummy Variable Expansion:** Categorical variables with $K$ categories expand into $K$ binary indicator columns (or $K-1$ when dropping reference levels). This transforms qualitative survey answers into an algebraic vector space.
- **Standardization:** Transforms features to have $\mu = 0$ and $\sigma = 1$, preventing high-magnitude features from dominating distance metrics.

## B. Implementation in AcademiQ
- **Dimensions:** Exactly **5,285 rows** $\times$ **44 columns** (43 preprocessed features + 1 target `Exam_Score`).
- **Column Composition:**
  - 6 numerical columns scaled via `StandardScaler` (`num__Hours_Studied`, `num__Attendance`, etc.).
  - 37 dummy indicator columns generated via `OneHotEncoder` without dropping reference levels (`cat__Parental_Involvement_High`, etc.) for complete structural analysis.
- **Generated By:** `AcademiQ_02_Preprocessing.ipynb`.

## C. Significance in the Complete Project
- **Workflow Position:** Stage 02 output; numeric matrix representation of training data.
- **Downstream Consumers:** Ingested directly by `AcademiQ_04_Feature_Analysis.ipynb` (for SelectKBest univariate feature scoring) and available for modular verification of the preprocessing transformations.
