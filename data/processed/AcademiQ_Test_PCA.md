# Companion Explanation: AcademiQ_Test_PCA.csv

## A. Academic Understanding: Out-of-Sample Latent Projections
- **Projection onto Frozen Eigenvectors:** Transforming unseen test samples into PCA space requires projecting them onto the eigenvectors learned from training data: $\mathbf{Z}_{	ext{test}} = \mathbf{X}_{	ext{test}} \mathbf{V}_{	ext{train}}$.
- **No Test Eigenvalue Estimation:** Test data must never be used to recalculate covariance matrices or eigenvalues, as this would violate validation independence.

## B. Implementation in AcademiQ
- **Dimensions:** Exactly **1,322 rows** $\times$ **25 columns** (`PC1` through `PC24` + target `Exam_Score`).
