# Companion Explanation: AcademiQ_Train_Clustered.csv

## A. Academic Understanding: Semi-Supervised Data Enrichment & Profiling
- **Appending Unsupervised Discoveries:** In exploratory data mining, unsupervised cluster assignments can be appended as new categorical features to historical data. This enables researchers to cross-tabulate cluster labels against external demographic attributes and target performance.
- **Post-Hoc Analysis:** Inspecting how clusters correlate with an unclustered target (`Exam_Score`) reveals whether unsupervised geometric boundaries align with real-world outcomes.

## B. Implementation in AcademiQ
- **Dimensions:** Exactly **5,285 rows** $\times$ **21 columns** (20 original features + `Cluster`).
- **Cluster Distribution:** Cluster 0 ($2,590$ students, $49.0\%$), Cluster 1 ($2,695$ students, $51.0\%$).
- **Generated By:** `AcademiQ_05_Clustering.ipynb` using fitted $K$-Means ($K=2$).
