# Companion Explanation: AcademiQ_Classification_Test_Results.csv

## A. Academic Understanding: Multi-Class Evaluation Metrics
- **Accuracy Pitfall:** Accuracy measures overall percentage correct, but can mask poor performance on critical minority classes.
- **Precision, Recall & Macro F1:**
  - *Precision:* $\frac{\text{TP}}{\text{TP} + \text{FP}}$ — Measures alert quality (few false alarms).
  - *Recall:* $\frac{\text{TP}}{\text{TP} + \text{FN}}$ — Measures safety/coverage (catches all struggling students).
  - *Macro F1:* Unweighted mean of class F1 scores: $\frac{1}{K}\sum F1_k$. Treats all 3 tiers (Developing, Proficient, Advanced) with equal importance, preventing majority class dominance.
