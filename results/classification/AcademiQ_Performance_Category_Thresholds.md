# Companion Explanation: AcademiQ_Performance_Category_Thresholds.csv

## A. Academic Understanding: Target Discretization & Data Leakage Prevention
- **Quantile Cutoffs vs Arbitrary Thresholds:** Arbitrary cutoffs (e.g., pass/fail at 50) can create extreme class imbalance. Splitting training scores into equal-frequency tertiles ($33.3\%$ each) guarantees balanced class support.
- **The Freezing Rule:** Cutoff boundaries must be derived strictly from the training score distribution and frozen. If test score quantiles are calculated separately, it constitutes target distribution leakage.
