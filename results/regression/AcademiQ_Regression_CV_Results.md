# Companion Explanation: AcademiQ_Regression_CV_Results.csv

## A. Academic Understanding: K-Fold Cross-Validation for Variance Estimation
- **Why a Single Split Is Not Enough:** An 80:20 split gives only one evaluation estimate, which may be lucky or unlucky depending on random split draws.
- **5-Fold Cross-Validation Mechanics:** Partitions training data ($5,285$ rows) into 5 equal folds. Trains on 4 folds, tests on the 5th, and repeats 5 times. The mean metric estimates expected performance, while standard deviation measures model stability.

## B. Implementation in AcademiQ
- **What Each Row Represents:** Average cross-validation score across 5 validation folds for each candidate regression pipeline.
