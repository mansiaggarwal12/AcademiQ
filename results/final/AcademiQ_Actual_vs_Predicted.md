# Companion Explanation: AcademiQ_Actual_vs_Predicted.png

## 1. Academic Understanding: Residual Diagnostics and Model Goodness-of-Fit

### Diagnostic Value of Actual vs. Predicted and Residual Visualizations
While aggregate summary metrics such as $R^2$, MAE, and RMSE quantify general accuracy, graphical residual diagnostics are critical to confirm that Ordinary Least Squares assumptions hold:
1. **Linearity & Parity:** Plotting actual ground-truth values against predicted outputs alongside a $45^\circ$ dashed identity line ($y = \hat{y}$) reveals whether predictions are systematically under- or over-estimated across score tiers.
2. **Homoscedasticity & Normality of Errors:** Residuals ($e_i = y_i - \hat{y}_i$) must be zero-centered, bell-shaped, and display constant variance across the prediction spectrum without non-linear funneling or skew.

## 2. Implementation in AcademiQ

### Visual Layout and Observed Diagnostics
`AcademiQ_Actual_vs_Predicted.png` is generated by `AcademiQ_03_Regression.ipynb` on the 1,322 holdout test observations using the champion Multiple Linear Regression model:

- **Left Panel (Actual vs. Predicted Scatter):**
  - Displays actual test scores on the horizontal axis and predicted scores on the vertical axis.
  - Data points tightly cluster along the dashed red 1:1 reference line ($y = \hat{y}$), illustrating strong alignment ($R^2 = 0.77$).
  - Scatter remains uniformly distributed across low, medium, and high performance bands.

- **Right Panel (Residual Distribution Histogram):**
  - Displays error frequencies ($y_{test} - y_{pred}$) centered at zero.
  - **Mean Residual:** $-0.0483 \approx 0.00$, confirming unbiased predictions.
  - **Standard Deviation:** $1.8027$, closely matching the test RMSE of $1.8033$.
  - Symmetrical Gaussian shape confirms error normality and homoscedasticity.
