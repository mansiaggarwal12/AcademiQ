## 1. Academic Understanding: Target Variable Distribution Analysis

### Why Distribution Analysis Matters in Regression
Before training continuous supervised regression models, analyzing the distribution of the target variable ($y = 	ext{Exam\_Score}$) is essential for several reasons:
1. **Normality and Symmetry:** Linear regression assumes that residuals are normally distributed with constant variance (homoscedasticity). A well-behaved, symmetric target variable strongly supports this assumption.
2. **Central Tendency and Dispersion:** Identifying the mean, median, standard deviation, and interquartile range establishes a statistical baseline against which model predictions and error magnitudes (MAE, RMSE) can be evaluated.
3. **Anomaly and Boundary Detection:** Checking min-max boundaries ensures valid values (e.g., scores within the valid 0–100 academic boundary) and reveals any extreme truncation or ceiling/floor effects.
