# Companion Explanation: AcademiQ_Feature_Selection_Results.csv

## 1. Academic Understanding: Univariate Hypothesis Testing with F-Regression

### Testing Linear Significance
`AcademiQ_Feature_Selection_Results.csv` documents the results of univariate hypothesis testing between each candidate feature and the continuous target `Exam_Score`.
The function `f_regression` computes the Pearson correlation $r$ between each individual feature and `Exam_Score`, then converts it to an $F$-statistic:
$$F = \frac{r^2}{1 - r^2}(n - 2) \sim \mathcal{F}(1, n - 2)$$
With $n = 5,285$ training students, the degrees of freedom are $(1, 5283)$. A critical $F$-value at $\alpha = 0.001$ is approximately $10.83$. Features with $F$-scores well above this threshold possess extremely strong individual linear associations with examination performance.

### Essential Limitation: Predictive Association vs. Causation
These $F$-scores quantify empirical correlation within historical observational data. They do not constitute experimental proof of causation or guarantee real-world score increases if an individual student changes a single behavior.
